One sentence in, a playable 3D game out

Agentic Game Studio turns a plain-language prompt into a real-time 3D game: designed on Meta models, built from real geometry, and held to deterministic verification gates before anything reaches the screen. This page shows the stack, the evidence, and a receipt you can reproduce live.

01Muse Wonder 1.0

High-Reasoning Architect & HFSM Behavior Designer

Wonder is the high-reasoning architect. For every build prompt it returns a structured design as JSON — a one-sentence objective plus exactly three focal assets, each tagged with a role (player, collectible, or obstacle). The pipeline builds the world from that contract, and every saved spec records which model actually answered.

  • Architect client: src/agent/muse_wonder.js via MetaWonderClient in src/agent/meta_wonder.js.
  • Spec stamps the winner as architectModel: "muse-wonder-1.0"; Baseten enriches the same design as a second opinion.
  • Also selectable in the composer model picker alongside the Muse Spark family.

02Baseten meta-models/muse-spark-open-1026

Live Runtime In-Game AI Director: Agatha tactics + Hindi whispers + environment blackouts/storms

While you play, POST /api/studio/ai/director reads flat gameplay telemetry (room, enemy state, torch, key, distance, noise) and answers with one flat JSON decision: an enemy tactic, a target room, a short Hindi/English whisper reacting to your exact situation, and an environment event with fog, light, and ash levels the renderer applies live.

  • 4 tactics (ambush_room, cut_off_chapel, stalk_shadow, inspect_hideout) and 4 environment events (lantern_blackout, storm_surge, ash_vortex, chapel_omen) — every field clamped server-side.
  • 20-second state-signature cache (repeat states cost zero credits), 3.5 s model timeout, and a deterministic heuristic fallback under 5 ms on any failure — the game never waits on the network.
  • Default model meta-models/muse-spark-open-1026 (src/agent/baseten_muse.js), surfaced in health as plannerModel; 30 requests/min per IP.

04Muse Image 1.0

Concept art & material refs

Image 1.0 is offered in the composer model picker and served by a dedicated script that calls the Meta Model API directly with the VM key — independent of whichever chat model is active. Its concept frames feed the SAM 3.1 segmentation pass and the PBR material references the world builders work from.

  • Picker option muse-image-1.0 in public/index.html; generation path src/tools/make-image.js and src/pipeline/meta_image.js.
  • Segmented outputs land in public/assets/evidence/ and project onto meshes (see 03).

05Muse Voice Transcribe 1.0

ASR voice prompts & audio pipeline

Spoken prompts become text through two backends: the Meta Model API endpoint direct, or the Muse Code CLI voice command. Audio is normalized to mono WAV first, matching the API requirement, and a sample prompt ships in the repo.

  • Tool: src/tools/meta_voice_transcribe.js, model muse-voice-transcribe-1.0, endpoint POST api.meta.ai/v1/asr/transcribe.
  • Sample: public/assets/audio/voice_prompt_sample.wav (20,636 bytes, on disk).

07Meta MusicGen facebook/musicgen-small

Local 32kHz stalker drone & tension stems

The neural theme is generated by Meta's official MusicGen small model (300M parameters) at 32kHz from a text prompt, and ships as a WAV in the repo. Around it sit five procedural stems — ambience, sizzle, footstep, chime, impact — synthesized locally with zero dependencies.

  • Generator: src/tools/meta_musicgen_audio.py → public/assets/audio/musicgen_theme.wav (188,204 bytes).
  • Stems: bazaar_ambience, jalebi_sizzle, footstep_stone, collect_chime, impact_crash via src/tools/generate_game_audio.py.

09Deterministic verifiable agent gates

visual_qa_gate 6/6 · physics_qa_gate BFS reachability · automated tests 81/81

Nothing reaches the preview unverified. The visual gate runs 6 checks, the physics gate runs 4 proofs over the same layout the renderer draws, and the automated suite passes 67 of 67 — run in this repo on Nov 3.

  • Visual (src/verifier/visual_qa_gate.js): CSP zero inline scripts/handlers; real .glb via GLTFLoader required; primitive fakes banned; 3D instanced wind-sway grass; ACES tone mapping; radial map on every PointsMaterial.
  • Physics (src/verifier/physics_qa_gate.js): CCD zero-tunneling at 60Hz; camera clearance; jump-arc sanity; BFS flood-fill reachability of every orb (count varies per layout).
  • Suite: node --test --test-concurrency=1 test/ → 81/81 (README's 59/59 line is stale).

LBuilt this week (Oct 26 – Nov 4, 2026) & limits, stated plainly

What is deterministic, what is AI-driven, and where the VM ends

Deterministic: the 6 visual-gate checks, the 4 physics proofs, the 81/81 automated suite, the 20s director cache, and the <5ms heuristic and KB fallbacks — all runnable locally with no network. AI-driven: Wonder's designs, the Baseten director's tactics and whispers, the MusicGen theme, Image concepts, and SAM segmentation (each pinned to a recorded model id, each with a fallback).

VM limits: this VM has no local GPU, so neural 3D (SAM 3D Objects, VGGT-1B) runs on Modal GPUs with cold starts that dominate wall time — the trial logs disclose that instead of hiding it. The 3D preview itself renders in your browser via WebGL, not on the VM.
